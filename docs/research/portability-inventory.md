# Portability audit file inventory

Archived research from 2026-10-18, imported for issue #1. Repository-relative statements and counts describe the frozen source snapshots named below. Original source-file links point to the reviewed Cursor commit; this report is not an installation guide or a claim about completed roadmap work.

Companion to the [portability audit and improvement plan](portability-audit.md). This inventory covers all **171 tracked source files** at commit `933da29fe88f64e715d1a446fd1ce045b429e5ef`, before the two audit documents were added. It includes 164 text files and seven visually inspected images. Findings identify dependencies or policy choices, not an instruction to rewrite every file. `None` means no environment coupling was identified in that file.

All main skills share an installation and metadata concern even when their body is portable. Repeated references inherit the dependency of the workflow they call. Test rows distinguish source inspection from execution. Integration and harness compatibility have not been established by the focused test run.
